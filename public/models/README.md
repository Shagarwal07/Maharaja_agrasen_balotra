# 3D Models Directory for Maharaja Agrasen Portal

Place your 3D Maharaja Agrasen model in this folder:
- **Recommended File Name**: `maharaja_agrasen.glb`
- **Supported Formats**: `.glb` (Binary GLTF, recommended), `.gltf`
- **Recommended Size**: 2MB - 15MB for fast loading on all devices.

When `maharaja_agrasen.glb` is placed here, the 3D Viewer on the website will automatically load and display it on the golden pedestal.
If the file is not present, the viewer gracefully falls back to the illuminated 3D relief mockup.
